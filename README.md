# Godot Mechanics

## About
This is a Godot Engine project designed to demonstrate core gameplay mechanics. The project serves as a functional template showcasing character movement, jumping logic, attack actions, and scene transitions. 

## Features
* Modular scene architecture using Godot's node system.
* GDScript implementation of state-based character movement (run, jump, attack).
* Structured scene management for transitioning between levels or menus.
* Separation of scripts, scenes, and visual assets.

## Repository Layout
```text
project.godot    # Godot project configuration file
scenes/          # .tscn files for levels, characters, and UI
scripts/         # .gd scripts containing core game logic
assets/          # Sprites, audio, and tilemaps
```

## How to Build Step by Step

Follow these instructions to open and run the game on your local machine.

**Prerequisites:**
* [Godot Engine](https://godotengine.org/download) (Version 4.0+)
* Git

**Step 1: Clone the repository**
Open your terminal and pull the code to your local machine.
```bash
git clone [https://github.com/Jimmyu2foru18/new-game-project.git](https://github.com/Jimmyu2foru18/new-game-project.git)
```

**Step 2: Import the project**
1. Open the Godot Project Manager.
2. Click **Import**.
3. Navigate to the cloned `new-game-project` folder.
4. Select the `project.godot` file and click **Import & Edit**.

**Step 3: Run the game**
Once the editor opens, press **F5** (or click the Play icon in the top right) to run the main scene and test the mechanics.
